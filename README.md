## Observação técnica

Os arquivos estão em formato `.docx` (Microsoft Word) para garantir compatibilidade máxima com sistemas de rastreamento de candidatos (ATS) e leitores de currículo utilizados por departamentos de RH, que em geral processam esse formato com maior confiabilidade do que PDFs gerados a partir de exportações não padronizadas.
